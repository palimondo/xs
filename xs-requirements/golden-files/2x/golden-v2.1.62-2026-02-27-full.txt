⏺ Here's what I found about Claude Code session transcript format:

  Storage: Claude Code stores session transcripts as JSONL files in ~/.claude/projects/<project>/sessions/, with each
  session named by UUID.

  Format: Each JSONL file contains typed message records linked by parentUuid, including:
  - User prompts and assistant responses (text, tool calls, thinking blocks)
  - Tool results with exact inputs/outputs
  - Subagent spawning events
  - Token usage, model selection, working directory, and git state snapshots

  Metadata: A sessions-index.json file contains summaries, message counts, git branches, and timestamps.

  Tools for viewing transcripts:
  - https://github.com/simonw/claude-code-transcripts by Simon Willison — converts JSONL to readable HTML
  - https://github.com/daaain/claude-code-log — another Python CLI for HTML conversion

  Sources:
  - https://github.com/simonw/claude-code-transcripts
  - https://simonw.substack.com/p/a-new-way-to-extract-detailed-transcripts
  - https://medium.com/@databunny/inside-claude-code-the-session-file-format-and-how-to-inspect-it-b9998e66d56b
  - https://kentgigger.com/posts/claude-code-conversation-history
  - https://github.com/daaain/claude-code-log
